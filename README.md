# ML_RGR

Актуальность темы данной расчетно-графической работы обусловлена стремительным ростом применения технологий машинного обучения (ML) в реальных бизнес-процессах. Однако сама по себе обученная модель не приносит ценности, пока она не интегрирована в производственную среду. Процесс инференса (вывода) моделей ML позволяет применять математические алгоритмы к новым данным и генерировать прогнозы для конечных пользователей. Создание аналитических информационных панелей (дашбордов) является наиболее эффективным способом демонстрации возможностей моделей, визуализации данных и предоставления интуитивно понятного интерфейса для взаимодействия с алгоритмами без необходимости написания кода.
Для реализации поставленной задачи был выбран современный стек технологий на базе языка программирования Python. Ключевым инструментом разработки веб-интерфейса выступила библиотека Streamlit, которая позволяет создавать интерактивные приложения с минимальными затратами времени. Для построения и сериализации моделей использовались библиотеки Scikit-learn, CatBoost и Keras (TensorFlow). Обработка данных и визуализация реализованы с помощью Pandas, Matplotlib и Seaborn.
Целью данной работы является разработка веб-приложения (дашборда) для инференса моделей машинного обучения и представления результатов анализа данных на задаче регрессии (прогнозирование стоимости подержанных автомобилей).
Для достижения поставленной цели необходимо решить следующие задачи:
1)	Обучить и сериализовать шесть различных моделей машинного обучения (классическую, ансамблевые и нейронную сеть) для решения задачи регрессии.
2)	Разработать веб-приложение на базе Streamlit, включающее страницы с информацией о разработчике, описании датасета, визуализации данных и интерфейсом для получения прогнозов.
3)	Провести тестирование приложения на корректных данных и данных с выбросами, проанализировавать полученные результаты и оценить согласованность предсказаний ансамбля моделей.

В ходе выполнения расчетно-графической работы была достигнута поставленная цель: разработано веб-приложение (дашборд) для инференса моделей машинного обучения и анализа данных на задаче регрессии.
В процессе работы были решены следующие задачи:
1)	Проведен сравнительный анализ и обучены шесть моделей машинного обучения (Ridge, Gradient Boosting, CatBoost, Random Forest, Stacking, Keras FCNN). Модели успешно сериализованы с использованием специализированных инструментов (joblib, нативные методы CatBoost и Keras).
2)	Разработано интерактивное веб-приложение на базе библиотеки Streamlit. Реализован удобный пользовательский интерфейс, включающий загрузку данных в формате .csv, ручной ввод параметров, визуализацию статистических зависимостей и наглядный вывод результатов прогнозирования в денежном формате.
3)	Проведено тестирование приложения. Анализ результатов показал, что на корректных данных ансамбль моделей демонстрирует высокую согласованность и точность. На данных с выбросами наблюдается ожидаемый разброс предсказаний, однако использование усредненного значения по ансамблю позволяет получить более робастную оценку.
Разработанное приложение может быть использовано как прототип реального сервиса для оценки стоимости подержанных автомобилей, а полученные навыки подтверждают готовность к развертыванию ML-моделей в производственной среде.
